Section 5: 后台服务 & 项目结构

令牌心跳检测流程、环境配置、项目目录结构、Docker Compose 编排

5a. 令牌心跳检测流程

Worker 定时任务 — 每 5 分钟一轮
Step 1

扫描目标

查询 token_checked_at 超过 5 分钟或 token_status = "expired" 的邮箱批次

→
Step 2

标记检测中

批量更新 token_status = "checking"，前端轮询立即展示黄灯

→
Step 3

解密 & 刷新

解密 refresh_token，调用 MSAL 换取新 access_token，并发限制 10 个/秒

→
Step 4

更新状态

成功 → "normal" + 缓存 access_token 到 Redis (TTL 50min)；失败 → "expired"

5b. 关键环境变量

变量名默认值说明
ENCRYPTION_KEY （必填） AES-256 加密主密钥，base64 编码 32 字节
DATABASE_URL postgresql://... PostgreSQL 连接字符串
REDIS_URL redis://redis:6379/0 Redis 连接（ARQ 队列 + Token 缓存）
TOKEN_CHECK_INTERVAL 300 令牌心跳检测间隔（秒），默认 5 分钟
TOKEN_CHECK_CONCURRENCY 10 令牌刷新并发数上限，避免 Graph API 限流
ACCESS_TOKEN_CACHE_TTL 3000 Access Token Redis 缓存 TTL（秒），默认 50 分钟
FRONTEND_POLL_INTERVAL 30 前端令牌状态轮询间隔（秒）

5d. Docker Compose 服务编排

🐳 docker-compose.yml
frontend node:20 → nginx:alpine 3000:80 多阶段构建：Vite build → Nginx 静态服务
api python:3.12-slim 8000:8000 FastAPI + Uvicorn，depends_on: postgres, redis
worker python:3.12-slim — ARQ worker，共享 backend/ 代码，无端口暴露
postgres postgres:16-alpine 5432:5432 持久化 volume: pgdata，自动执行 init SQL
redis redis:7-alpine 6379:6379 ARQ 队列 + Access Token 缓存
