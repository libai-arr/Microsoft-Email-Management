Section 1: System Architecture

Docker Compose 部署架构 — 4 个容器 + Redis

Frontend Container

React SPA

邮箱管理主列表、批量操作、导入模态框、邮件在线查看。使用 Ant Design 组件库（ProTable, Modal, Tag, Badge）。Vite 构建，Nginx 静态服务。

React 18 + TypeScript + Ant Design 5 + Vite

Nginx

静态文件服务 + API 反向代理。所有 /api/* 请求转发至后端容器。

nginx:alpine
↓ HTTP /api/*
API Container

FastAPI 应用

RESTful API：邮箱 CRUD、批量操作、导入解析、邮件拉取代理。Uvicorn ASGI 服务。

Python 3.12 + FastAPI + SQLAlchemy + Uvicorn

加密服务

AES-256-GCM 对称加密。密码、Client_ID、Refresh Token 密文存储，运行时解密。

cryptography (Fernet / AES-GCM)

Graph API 客户端

调用 Microsoft Graph API 获取邮件列表和邮件正文。使用 Refresh Token 换取 Access Token。

httpx + msal
↓ SQLAlchemy       ↓ ARQ tasks
Data & Worker Layer

PostgreSQL

核心数据存储：邮箱账户、分组、加密凭证、审计日志。

postgres:16-alpine

Redis

ARQ 任务队列 + Access Token 短期缓存（避免重复刷新）。

redis:7-alpine

Worker 容器

后台常驻进程：定时令牌心跳检测、批量状态更新。与 API 共享代码，独立运行。

ARQ worker (Python)
docker-compose.yml — 5 services: frontend · api · worker · postgres · redis

Key Data Flows

用户导入 → 前端解析校验 → POST /api/mailboxes/import → AES-256 加密 → PostgreSQL
Worker 定时任务 → 解密 Refresh Token → Graph API 刷新 → 更新令牌状态 → 前端轮询展示
查看邮件 → GET /api/mailboxes/{id}/emails → 解密 Token → Graph API → 懒加载分页返回 → HTML 安全渲染
